# Python Analog Clock

**Objective:** To develop a real-time analog clock application using Python.

**Description:** This project uses Python's Tkinter library to create a graphical user interface and the Math library to calculate the positions of the clock hands. The application displays hour, minute, and second hands and updates the current time every second.

**Technologies Used:**
- Python
- Tkinter
- Math
- Time

**Key Features:**
- Real-time clock display
- Moving hour, minute, and second hands
- Clock numbers and minute markers
- Digital time display
- User-friendly graphical interface

**Conclusion:** This project helped me understand Python GUI development, mathematical calculations, time handling, and event scheduling.
